# Portable package note

This package is the reduced-size distribution build of the NEO Mathematics
Year 9 Pythagoras 10-session prototype v0.1.

## Difference from the full local-media package

- `The Harmony of Numbers` is streamed from Gerrard Docherty's Vimeo-hosted
  film using the supplied unlisted video hash.
- The local 1080p Harmony MP4 is not included.
- The Henry Perigal and Hippasus speaking videos remain included locally.
- All lesson HTML, interactives, Scratchpad features, Practice Companions,
  guidance PDFs and QA records are retained.

This significantly reduces the package size while preserving the intended
learner experience when an internet connection is available for Session 1.
