# NEO Mathematics — Unit Blueprint: Straight Lines and Connected Representations
**Pathway:** Intermediate (internal stage code Y10) · **Term:** Autumn, Half-Term 1
**Shape:** 18 lessons = 6 weeks × 3 lessons/week · 45 minutes each
**Qualification overlay:** Pearson Edexcel International GCSE (4MA1) algebra/graphs; NC KS3/KS4 graphs
**Status (v0.1):** blueprint framed; lessons built and reviewed one at a time.

## Unit Driving Question
Can a line tell the same story as an equation, a table and a graph — and what do its two numbers, *m* and *c*, actually mean?

## The mathematical story
A straight line is a single relationship wearing many costumes: a context, a table, a set of
coordinates, an equation, and a graph. This unit builds the learner's power to **move between
those representations at will**, then to read the two numbers that control every line — *c*, the
*y*-intercept (where the line meets the *y*-axis), and *m*, the constant rate of change
(gradient). From there it grows outward: finding a gradient from two points, writing *y = mx + c*
from clues, and then lines **in relation to each other** — parallel lines, intersections
(break-even/equal-value points), and conversion graphs. It closes by asking where a perfect line
stops being a good model, translating assessment wording into canonical moves, and synthesising
everything into a defended linear model.

**Arc:** represent → read the dials (c, then m) → find & write the line → lines together →
model, limits, assess → synthesise.

## Stepping Stones
Connect linear representations · generate graph points and recognise constant rate · identify and
interpret the *y*-intercept (*c*) · identify and interpret gradient (*m*) · find gradient from two
points · write linear equations · identify parallel lines · interpret intersections · interpret and
use conversion graphs · evaluate linear models · select and connect representations strategically.

## Cornerstone emphasis across the unit
Strongest Cornerstones for connected linear reasoning are **Connection** (moving between
representations), **Movement** (gradient as change), and **Reflection** (interpreting, checking,
choosing). Creativity anchors the modelling and portfolio work; Rest anchors the synthesis
checkpoint. Nutrition is contextual throughout — tariffs, conversions, journeys and break-even
decisions are all straight-line stories.

## Reconnection Routes used
REC-ALG-03 (substitution), REC-ALG-07 (coordinates and axes), REC-ALG-08 (rule → ordered pairs),
REC-NUM-02 (directed number), REC-NUM-05 (fractions). Assigned adaptively where a prerequisite
check indicates need; SL-R1 and SL-R2 are the two scheduled whole-group reconnection sessions.

## Resource reuse — one environment, many lessons
Unlike the 2D and 3D Shapes unit (bespoke 3D interactive per lesson), this unit is built on **one
shared Straight-Line Graphs environment** — linked table ⇄ coordinates ⇄ equation ⇄ graph with
*m* and *c* controls. Each lesson is a **preset + framing** of that environment (Intercept
Isolator, Gradient Isolator, Gradient Triangle Builder, Line Detective, Parallel Challenge, Cost
Comparison, Conversion Translator, Question Translator, Mastery Map, Portfolio). Existing repo
prototypes `straight-line-graphs` and `equation-of-a-straight-line` seed this environment. Build
the shared spine once, then reskin per lesson — this is what makes 18 lessons by month-end viable.

## Build approach
Frame one lesson → present a 3–5 option interactive bank → build the full ecosystem (interactive,
Practice Companion, Scratchpad, Learner + Supporting Adult guidance) → QA → review. Keep British
English, "learner" not "student", NEO Cornerstones, no year labels in learner-facing text.
